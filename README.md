#  WordPress Website Project

This project is a fully functional website developed using WordPress.  
It demonstrates content management, UI/UX customization, and plugin integration.

##  Demo

A short video demonstration of the website is included in this repository.

##  Features

- Custom pages (Home, About, Contact)
- Responsive design (mobile-friendly)
- Multilingual support
- Image gallery integration
- Contact forms
- SEO optimization basics
- Custom UI/UX styling

##  Theme Used

- **Astra Theme**  
  A lightweight and highly customizable WordPress theme used for building a responsive and modern user interface.
##  Plugins Used

The website utilizes the following WordPress plugins to extend functionality:

- **Complianz | GDPR/CCPA Cookie Consent**  
  Cookie consent management and privacy compliance.

- **Contact Form 7**  
  Creation and management of contact forms.

- **FooGallery**  
  Image gallery management.

- **Media Sync**  
  Synchronization of media files.

- **Polylang**  
  Multilingual content support.

- **Simple Custom CSS and JS**  
  Custom styling and scripting.

- **WordPress Importer**  
  Importing WordPress content.

- **WP Mail SMTP**  
  Email configuration.

- **WP Reset**  
  Development and testing utility.

- **WPForms Lite**  
  Form builder for additional forms.

##  Technologies Used

- WordPress (CMS)
- PHP
- MySQL
- HTML / CSS / JavaScript

##  Project Structure

- `wp-content/` – themes, plugins, uploads  
- `wp-admin/` – admin dashboard  
- `wp-includes/` – core WordPress files
